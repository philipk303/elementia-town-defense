# Snare Post source lineage

Approved 2026-08-09 GPT Image draft: compact, walkable feudal Japan/China-inspired
defensive snare post with dark wood, a small terracotta tile eave, a braided rope
ground loop, folded paper ward, and restrained jade-green vine accents. The source
uses a flat `#ff00ff` chroma background; `tools/art/snare_post_pipeline.py` removes
that background, normalizes both frames to 64 x 64 RGBA, and emits the Phaser atlas.
